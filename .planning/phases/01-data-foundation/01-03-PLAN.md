<objective>
Wire the scheduler, upsert layer, and market data API endpoint — completing the full data pipeline from scheduled fetch through DB storage to queryable REST endpoint.

Purpose: This plan closes the loop: data flows from external APIs through providers, gets persisted idempotently, and is accessible to downstream analysis components via a typed API. It is the delivery of Phase 1's primary goal.
Output: APScheduler jobs for stock (5min) and crypto (30min) ingestion, upsert helper, FastAPI market data endpoint, and the full test suite for multi-timeframe coverage and scheduler logic.

Note on scheduler choice: APScheduler (not Celery+Redis) is used here by deliberate Phase 1 decision, locked in STATE.md and confirmed in RESEARCH.md Alternatives Considered. APScheduler runs in-process with AsyncIOScheduler and integrates cleanly with FastAPI lifespan — no external queue infrastructure required for single-process MVP. Celery+Redis is the upgrade path for Phase 5+ when multi-worker scale is needed.
</objective>

<!-- APScheduler lifespan pattern (RESEARCH.md Pattern 6) -->
```python
from contextlib import asynccontextmanager
from apscheduler.schedulers.asyncio import AsyncIOScheduler
from apscheduler.triggers.interval import IntervalTrigger

scheduler = AsyncIOScheduler()

@asynccontextmanager
async def lifespan(app: FastAPI):
    scheduler.add_job(job_fn, trigger=IntervalTrigger(minutes=5), ...)
    scheduler.start()
    yield
    scheduler.shutdown(wait=False)
```

       from sqlalchemy import text
       from sqlalchemy.ext.asyncio import AsyncSession
       from app.ingestion.base_provider import OHLCVCandle
       import logging

       log = logging.getLogger(__name__)

       async def upsert_candles(session: AsyncSession, candles: list[OHLCVCandle]) -> int:
           if not candles:
               return 0
           for c in candles:
               await session.execute(
                   text("""
                       INSERT INTO market_data
                           (symbol, market, interval, timestamp, open, high, low, close, volume)
                       VALUES
                           (:symbol, :market, :interval, :timestamp, :open, :high, :low, :close, :volume)
                       ON CONFLICT (symbol, interval, timestamp) DO NOTHING
                   """),
                   {
                       "symbol": c.symbol, "market": c.market, "interval": c.interval,
                       "timestamp": c.timestamp, "open": c.open, "high": c.high,
                       "low": c.low, "close": c.close, "volume": c.volume,
                   },
               )
           await session.commit()
           log.info(f"Upserted {len(candles)} candles")
           return len(candles)
       ```

       from fastapi import APIRouter, Depends, Query
       from sqlalchemy.ext.asyncio import AsyncSession
       from sqlalchemy import select, and_
       from app.models.market_data import MarketData
       from app.core.database import get_session
       from typing import Annotated
       import logging

       log = logging.getLogger(__name__)
       router = APIRouter(prefix="/market-data", tags=["market-data"])

       VALID_INTERVALS = {"1m", "5m", "15m", "1H", "4H", "1D"}

       @router.get("/{symbol}")
       async def get_candles(
           symbol: str,
           interval: Annotated[str, Query(description="Candle interval: 1m|5m|15m|1H|4H|1D")],
           limit: Annotated[int, Query(ge=1, le=1000)] = 200,
           session: AsyncSession = Depends(get_session),
       ):
           if interval not in VALID_INTERVALS:
               from fastapi import HTTPException
               raise HTTPException(status_code=422, detail=f"Invalid interval: {interval}. Must be one of {VALID_INTERVALS}")
           result = await session.execute(
               select(MarketData)
               .where(and_(
                   MarketData.symbol == symbol.upper(),
                   MarketData.interval == interval,
               ))
               .order_by(MarketData.timestamp.desc())
               .limit(limit)
           )
           rows = result.scalars().all()
           return [
               {
                   "symbol": r.symbol, "market": r.market, "interval": r.interval,
                   "timestamp": r.timestamp.isoformat(), "open": r.open,
                   "high": r.high, "low": r.low, "close": r.close, "volume": r.volume,
               }
               for r in rows
           ]
       ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → FastAPI | Untrusted query parameters (symbol, interval, limit) from any caller |
| scheduler → DB | Async session per job; concurrent job runs could contend on same rows |
| upsert → TimescaleDB | Raw SQL with parameterized values; no user input in SQL template |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Injection | GET /api/market-data/{symbol} | mitigate | symbol is passed to SQLAlchemy .where(MarketData.symbol == symbol.upper()) — parameterized query, not string interpolation; interval validated against VALID_INTERVALS set before DB call |
| T-03-02 | Denial of Service | GET /api/market-data limit param | mitigate | Query param limit enforced ge=1, le=1000 by FastAPI Query annotation; requests above 1000 return 422 before reaching DB |
| T-03-03 | Denial of Service | APScheduler concurrent jobs | accept | Three jobs on different intervals (5min, 15min, 30min); APScheduler uses coalesce=False by default; misfire_grace_time=60 prevents pile-up; single-process MVP has no concurrency issue at this scale |
| T-03-04 | Injection | upsert_candles raw SQL | accept | All SQL values come from OHLCVCandle dataclass fields (typed floats/str/datetime); no user input reaches the SQL parameters; parameterized via SQLAlchemy text() with named params |
| T-03-05 | Elevation of Privilege | FastAPI has no auth on /api/market-data | accept | MVP is single-user local tool; no authentication required for Phase 1; auth is not in scope for this phase |
</threat_model>
