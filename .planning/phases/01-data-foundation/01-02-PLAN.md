from dataclasses import dataclass
from datetime import datetime
from abc import ABC, abstractmethod

@dataclass(frozen=True)
class OHLCVCandle:
    symbol: str
    market: str      # "stock" | "crypto"
    interval: str    # "1m" | "5m" | "15m" | "1H" | "4H" | "1D"
    timestamp: datetime  # must be timezone-aware
    open: float
    high: float
    low: float
    close: float
    volume: float

class OHLCVProvider(ABC):
    @abstractmethod
    async def fetch_historical(
        self, symbol: str, interval: str, start: datetime, end: datetime
    ) -> list[OHLCVCandle]: ...

    @abstractmethod
    async def fetch_latest(
        self, symbol: str, interval: str
    ) -> list[OHLCVCandle]: ...
```

       import time
       from typing import Any

       class TTLCache:
           def __init__(self):
               self._store: dict[str, tuple[Any, float]] = {}

           def get(self, key: str) -> Any | None:
               entry = self._store.get(key)
               if entry is None:
                   return None
               value, expiry = entry
               if time.monotonic() > expiry:
                   del self._store[key]
                   return None
               return value

           def set(self, key: str, value: Any, ttl_seconds: int = 60) -> None:
               self._store[key] = (value, time.monotonic() + ttl_seconds)

           def invalidate(self, key: str) -> None:
               self._store.pop(key, None)
       ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| application → yfinance | Unofficial scraper; response structure can change without notice |
| application → CoinGecko API | External HTTP; API key transmitted in headers |
| application → Finnhub WebSocket | Persistent TCP connection; reconnect loop must not spin uncontrolled |
| application → CCXT/Binance | Public API; rate limits apply; IP ban risk if not respected |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Denial of Service | CoinGeckoProvider | mitigate | 120s TTL cache prevents repeated API calls; asyncio.sleep(2) between coins enforces max 2.5 req/min; monthly budget calculation (5 coins × 48 calls/day × 30 = 7,200 calls — within 10,000 cap) |
| T-02-02 | Denial of Service | yfinance backoff | mitigate | Exponential backoff with jitter (2^attempt + random) caps retry storm; 3-attempt max prevents infinite loops |
| T-02-03 | Denial of Service | FinnhubProvider reconnect | mitigate | 5-second sleep between reconnect attempts prevents CPU spin; ping_interval=20 detects dead connections proactively |
| T-02-04 | Information Disclosure | CoinGecko API key in settings | mitigate | API key sourced exclusively from COINGECKO_API_KEY env var via pydantic-settings; never hardcoded; .env gitignored |
| T-02-05 | Tampering | External API response injection | mitigate | All API responses pass through normalizer which type-casts every field to float/str/datetime; malformed responses raise ValueError before reaching DB |
| T-02-06 | Denial of Service | CCXT Binance rate limit | accept | ccxt.binance(enableRateLimit=True) handles Binance's rate limit automatically; no additional mitigation needed for single-user MVP |
</threat_model>
