       ```python
       from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession
       from contextlib import asynccontextmanager
       from app.core.config import settings

       engine = create_async_engine(settings.DATABASE_URL, echo=False)
       async_session_factory = async_sessionmaker(engine, expire_on_commit=False)

       @asynccontextmanager
       async def get_session() -> AsyncSession:
           async with async_session_factory() as session:
               try:
                   yield session
                   await session.commit()
               except Exception:
                   await session.rollback()
                   raise
       ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env → config | API keys loaded from .env file; must never be committed to source control |
| application → DB | SQLAlchemy sessions; SQL injection surface via any raw execute() call |
| application → external APIs | yfinance/CoinGecko/Finnhub responses are untrusted; must be validated before DB insertion |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | .env / config.py | mitigate | Add .env to .gitignore; .env.example contains no real keys; pydantic-settings validates env at startup, failing fast if required keys are missing |
| T-01-02 | Injection | alembic/versions/001 raw SQL | accept | DDL-only migration; no user input reaches SQL; table and column names are hardcoded string literals |
| T-01-03 | Injection | normalizer.py OHLCVCandle construction | mitigate | All fields typed (float, str, datetime); Pydantic or dataclass enforcement rejects wrong types; no raw SQL constructed from candle fields in this plan |
| T-01-04 | Tampering | docker-compose.yml DB credentials | accept | Default credentials (trading/trading) are dev-only; production must override via environment variables; document this in .env.example |
| T-01-05 | Information Disclosure | TimescaleDB Docker volume | accept | Single-user local dev; no network exposure beyond localhost:5432; ports binding limited to 127.0.0.1:5432 in production setup |
</threat_model>
