    1. Create api/client.ts:
       - BASE_URL = '' (empty — Vite proxy handles /api and /auth prefixes)
       - export async function apiFetch(path: string, init?: RequestInit): Promise<Response>
         - Always includes credentials: 'include'
         - Throws on network error; returns Response for callers to check status
       - export async function apiGet<T>(path: string): Promise<T>
         - Calls apiFetch, throws if !response.ok, returns response.json()
       - export async function apiPost<T>(path: string, body: unknown): Promise<T>
         - Calls apiFetch with method POST, JSON body, Content-Type header

    2. Create api/auth.ts:
       - loginUser(username: string, password: string): POST /auth/login using FormData (not JSON — OAuth2PasswordRequestForm requires form encoding)
         - const form = new FormData(); form.append('username', username); form.append('password', password)
         - fetch('/auth/login', { method: 'POST', body: form, credentials: 'include' })
         - Returns { ok: boolean; error?: string }
       - logoutUser(): POST /auth/logout with credentials: 'include'
       - getMe(): GET /auth/me → { username: string } | null

    3. Create store/auth.ts — Zustand store:
       interface AuthState {
         isAuthenticated: boolean
         username: string | null
         isLoading: boolean
         checkAuth: () => Promise<void>   // calls GET /auth/me on app load
         setAuthenticated: (username: string) => void
         clearAuth: () => void
       }
       - checkAuth: calls getMe(); if username returned → setAuthenticated; else clearAuth
       - setAuthenticated: sets isAuthenticated=true, username, isLoading=false
       - clearAuth: sets isAuthenticated=false, username=null, isLoading=false
       - Initialize isLoading=true (app calls checkAuth() on mount to restore session)

    4. Create router/PrivateRoute.tsx:
       - Reads useAuthStore().isAuthenticated and isLoading
       - isLoading=true → render full-screen centered spinner (Tailwind: flex items-center justify-center h-screen)

       - Otherwise → Outlet
