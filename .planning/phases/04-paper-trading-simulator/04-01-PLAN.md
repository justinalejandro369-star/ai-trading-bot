    Create backend/app/paper_trading/engine.py:
    - Module docstring: "Pure functions for paper trade simulation. No DB access, no FastAPI imports."
    - Import only: random, dataclasses, typing — NO sqlalchemy, NO fastapi
    - FillResult dataclass: fill_price (float), quantity (float), commission_paid (float), new_cash (float), realized_pnl (float)
    - fill_order(side, symbol, quantity, last_price, cash_balance, position_qty, avg_entry_price, slippage_std=0.001, commission=0.001) → FillResult:
      * Guard: if slippage_std == 0.0: offset = 0.0 else: offset = random.gauss(0, slippage_std) clipped to [-3*slippage_std, +3*slippage_std]
      * BUY: offset = abs(offset) so fills above mid; SELL: offset = -abs(offset) so fills below mid
      * fill_price = last_price * (1.0 + offset)
      * BUY: total_debit = fill_price * quantity * (1 + commission); if total_debit > cash_balance raise ValueError; new_cash = cash_balance - total_debit; realized_pnl = 0.0
      * SELL: if quantity > position_qty raise ValueError; gross_credit = fill_price * quantity * (1 - commission); realized_pnl = (fill_price - avg_entry_price) * quantity - (fill_price * quantity * commission); new_cash = cash_balance + gross_credit
    - compute_equity(cash, positions, last_prices) → float:
      * positions: list[dict] with keys "symbol", "quantity", "avg_entry_price"
      * For each position: use last_prices.get(symbol, avg_entry_price) as price
      * Return cash + sum of (quantity * price) for all positions
    - __all__ = ["FillResult", "fill_order", "compute_equity"]
